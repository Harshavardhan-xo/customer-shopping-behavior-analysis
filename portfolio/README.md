# Business Analytics Portfolio

Five end-to-end Business Analyst / Data Analyst builds generated from the supplied project briefs:

- RetainIQ — SaaS churn & revenue-at-risk
- FunnelIQ — marketing attribution & funnel ROI
- SupplyPulse — inventory forecasting & reorder risk
- AttritionRadar — employee attrition & workforce cost
- Monsoon-to-Margin — live weather + quick-commerce disruption analytics

Each project is self-contained with setup instructions, synthetic-data generation, application code, SQL where applicable, and tests.

> Existing repository content outside `portfolio/` is preserved.
